### 🧠 Design Intent (Why)
A typing cue and a one-tap retry are the two highest-value "live" touches and both stay
presentation-only (no agent-core or transcript-schema changes), keeping the diff small and green.
Gating the indicator on "not already streaming" avoids redundancy with the existing incremental
assistant rendering and the Agent's-view spinner. Scoping Retry to the last+idle error note keeps
it unambiguous (re-running a mid-history error would be confusing) and reuses the same readiness
routing as the composer's send. Timestamps + role grouping need a transcript/`StoredMessage`/
`SessionCodec` schema change, so they're split to 4.7b-3 to keep this slice focused.
