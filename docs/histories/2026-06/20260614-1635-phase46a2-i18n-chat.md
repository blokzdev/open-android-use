### 🧠 Design Intent (Why)

gets a `Context` only for string lookups (bounded, no logic change), via `AgentSettings`
rather than a new singleton dependency. Tool-chip verbs stay English to preserve the
pure-JVM test design; this is captured for the future Localization phase rather than forcing
those tests onto an Android runtime now.
