**Key Actions:**
- **Parser** (`ChatMarkdown`): `MdSpan` gains `url`; `parseInline` parses `[text](url)`

  with a brand-colored underline (`TextLinkStyles`); tables via `MarkdownTable`/`TableRow`
  in a `horizontalScroll` so wide tables don't overflow narrow screens (header bold). No new
  dependency — `LinkAnnotation` ships in Compose 1.7 (current BOM).
- **Tests**: `ChatMarkdownTest` += link parse, unmatched-bracket literal, pipe-table parse,
  no-separator fallback, link-inside-cell.
- **Docs**: 4.6 sub-plan + roadmap (4.6d done); `VERIFICATION.md` V82; this history.

### 🧠 Design Intent (Why)
Assistant answers increasingly use links and small tables; rendering them (vs. raw `[..](..)`
and `| .. |`) makes answers readable. Kept the parser pure so it's fully unit-tested, and the
Compose layer handles the framework bits (`LinkAnnotation`, horizontal-scroll tables) — no new
dependency. Tables scroll horizontally rather than squashing on phones.
