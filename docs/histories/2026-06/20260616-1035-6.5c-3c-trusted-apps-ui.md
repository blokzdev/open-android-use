### 🧠 Design Intent (Why)
This closes the grant lifecycle: persistent trust can now be created (effortful, risk-framed "Always"
in the takeover) and, crucially, **revoked** — so shipping the persistent tier doesn't leave a grant
that can only lapse by 30-day decay. The Trusted-apps list makes the trust state legible and reversible
(NIST 800-207 symmetric revocation; Android auto-reset decay), completing the "scoped, revocable,
decaying — never a blanket toggle" model. Persistent grants live in `TrustStore` (already decay-pruned
on read); the UI just surfaces + revokes them.
