  GRANT_SESSION remembers the app for the task, GRANT_ONCE allows just this action.

### 🧠 Design Intent (Why)
This realizes the three-layer invariant in code: redaction (L0) and element-level secret handoff
are never grant-aware; only the **screen-level** gate consults grants. A grant lets the agent
operate an app's *non-secret* controls on a screen that merely contains a secret field, without
re-asking — but typing into the secret itself always hands off. Session/once grants are in-memory
so trust never silently outlives a task (persistent tier + revocation UI is 3c). Every trusted
action is audited text-only (tool + resolved label, never a value).
