### 🧠 Design Intent (Why)
Chose a manual `WindowSizeClass` two-pane over the official `NavigableListDetailPaneScaffold`:
the chat carries heavy Activity-bound state (agent listener, permissions, speech, lifecycle,
`singleTask`) and the phone flow already works/tested — the manual Row reuses `ChatScreen`
as-is and adds a list pane only at Expanded width, far less risk for the same UX. Foldables
are covered via the width class; hinge-avoidance is a recorded follow-up. Layout is visual, so
the side-by-side result is the founder's tablet/AVD check (V83); the pure `TwoPane` decision is
unit-tested and `SessionsScreenTest` guards the list extraction.
