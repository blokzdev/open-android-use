### 🧠 Design Intent (Why)
"The agent never sees your secrets" was **false** on a payment screen: `label()` returns
`node.text` first, so a card field's typed digits rendered as the element name and reached
the model even in text-only mode. Redacting at **emission** is the one chokepoint that
covers both runtimes and stays byte-aligned (the Go bridge has no flatten-level redaction;
it just renders the already-redacted value). The screenshot — which the framework does not
redact — is withheld on sensitive screens with an explanatory note so the agent narrates
from the redacted tree and hands off rather than looping "I can't see". Redaction is never
grant-aware (a future per-app grant can relax the action gate, never un-redact a value).
